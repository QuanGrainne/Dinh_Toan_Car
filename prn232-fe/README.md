# 🚗 Car Sales Management System - Frontend Client (.NET 8 MVC)

Giao diện người dùng cho khách hàng và trang quản trị Admin xây dựng trên nền tảng **ASP.NET Core 8 MVC**.

## 🛠️ Công nghệ
- ASP.NET Core 8.0 MVC (Razor Views)
- Bootstrap 5, FontAwesome
- OData HttpClient Client Queries

## 🚀 Khởi chạy
```bash
dotnet restore
dotnet run --project CarSalesManagementSystemClient
```
- Client Web URL: `https://localhost:7117` hoặc `http://localhost:5242`

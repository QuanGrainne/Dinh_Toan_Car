# 🚗 Car Sales Management System - Backend API (.NET 8)

Hệ thống API backend xây dựng trên **ASP.NET Core 8 Web API**, tích hợp **Microsoft OData v8**, **Entity Framework Core 8** và **JWT Authentication**.

## 🛠️ Công nghệ
- .NET 8.0 SDK
- Microsoft.AspNetCore.OData 8.x
- Entity Framework Core 8.x (SQL Server)
- JWT Bearer Authentication & BCrypt

## 🚀 Khởi chạy
```bash
dotnet restore
dotnet run --project CarSalesManagementSystemAPI
```
- API Base URL: `http://localhost:5084`
- Swagger UI: `http://localhost:5084/swagger`
- OData Metadata: `http://localhost:5084/odata/$metadata`
